# 📔 My Journal App

A simple and responsive personal journal application built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://shamika-milani.github.io/journal-app/

## ✨ Features

- Create journal entries
- Edit journal entries
- Delete journal entries
- Favorite journal entries
- Search journals
- Filter journals by mood
- Character counter
- Date and time for entries
- Form validation
- Empty-state message
- Statistics dashboard
- Most-used mood tracking
- Dark mode / Light mode
- Responsive mobile design
- LocalStorage data persistence
- User feedback messages
- Smooth animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

## 📱 Responsive Design

The application is designed to work on:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet
